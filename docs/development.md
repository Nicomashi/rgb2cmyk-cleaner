# Разработка

Python-зависимости устанавливаются командой `uv sync --locked`. Для запуска и интеграционных тестов нужен CMYK ICC-профиль в `profiles/source-fogra39.icc`; тестовые проверки рассчитаны на FOGRA39.

## Проверки

```sh
uv run python -B -m pytest -q -p no:cacheprovider
node --test tests/probe-layout.test.mjs
node --check frontend/workspace.js
```

Тесты проверяют очистку каналов, ICC-преобразования, пробники, экспорт TIFF, отмену обработки и очистку рабочей сессии. Тестовые материалы создаются в изолированных каталогах.

## Сборка интерфейса

После изменений в `frontend/` пересоберите `static/ui.js` и включите его в коммит:

```sh
npm ci
npm run build
```

## Структура

- `app.py` — API и управление рабочей сессией.
- `cleaner/` — преобразование цвета, алгоритм очистки и экспорт.
- `frontend/` — исходники интерфейса.
- `static/` — файлы, которые получает браузер.
- `tests/` — тесты Python и JavaScript.
- `service.py` — управление автозапуском на macOS.

Загруженные материалы и экспорт временно хранятся в `.runtime/`, превью — в памяти. Новый файл, перезагрузка страницы или перезапуск сервера очищают рабочие данные. Каталоги `.runtime/` и `profiles/` исключены из Git.
