# RGB2CMYK Cleaner

**Проще всего поручить установку своему ИИ-агенту.** Скопируйте ему этот запрос:

> Установи и запусти RGB2CMYK Cleaner из https://github.com/Nicomashi/rgb2cmyk-cleaner на моём компьютере. Определи мою ОС, следуй инструкции в репозитории, установи зависимости через uv и помоги подключить CMYK ICC-профиль. Проверь открытие демо и экспорт TIFF, затем дай ссылку на приложение.

Для **Windows, Linux и macOS**. [Инструкция для самостоятельной установки](docs/installation.md).

Быстрая подготовка нейрокартинок к печати с более чистыми цветами — без сложной ручной цветокоррекции.

Лучше всего подходит для иллюстраций, плакатов и графики со сплошными заливками. Для фотографий людей подходит меньше: очистка может заметно изменить оттенки кожи.

![CMYK Clean: сравнение до и после очистки, настройки и цветовые пробники](docs/images/cmyk-clean-preview.png)

## Как это работает

Приложение переводит изображение в CMYK по печатному ICC-профилю, уменьшает примесь лишней цветной краски и компенсирует её чёрной. Силу очистки и компенсацию можно настроить, сразу сравнивая результат с исходником.

1. Откройте изображение или нажмите «Демо», чтобы попробовать.
2. Подберите очистку и компенсацию K. Перетаскивайте разделитель для сравнения до и после.
3. Нажмите «Скачать TIFF» — получите CMYK-файл в исходном разрешении со встроенным ICC-профилем.

Для просмотра используется уменьшенное превью, для экспорта — оригинал. Результат на экране помогает подобрать настройки; перед тиражом стоит сделать пробную печать.

## Установка и запуск

Выберите свою систему: [Windows](docs/installation.md#windows), [Linux](docs/installation.md#linux) или [macOS](docs/installation.md#macos).

На всех трёх системах приложение запускается локально и открывается в браузере по адресу **http://127.0.0.1:8765**. Интерфейс уже собран; Node.js не нужен.

## Управление

- **Колесо мыши** — масштаб; **Пробел + перетаскивание** — перемещение изображения.
- **Наведение мыши** — значения CMYK под курсором.
- **Shift + клик** — закрепить пробник; значения обновляются при изменении настроек.
- **Alt / Option** — показать значения рядом с пробниками на изображении.
- **«Слева»** — переключить сравнение между CMYK до очистки и исходником.

## Форматы и сохранение

Поддерживаются одностраничные 8-битные PNG, JPEG и TIFF. Для CMYK-исходника нужен встроенный ICC-профиль; RGB без профиля считается sRGB. Прозрачность сводится на белый фон. PDF, 16-битные изображения и слои пока не поддерживаются.

Скачайте результат перед закрытием или обновлением страницы. Новый файл или перезагрузка очищают рабочую сессию; исходники и скачанные файлы остаются у вас. Используйте одну вкладку: открытие второй сбрасывает текущую работу.
